# Problems — Intuition-First Solutions, The Google 50

50 Google-tagged LeetCode problems, one file each, grouped by the pattern that cracks them. Every file walks the **same path a strong candidate walks in the room**:

> 🧠 **Intuition** (how you arrive at each approach) → ① **Brute Force** (and why it times out) → ② **Optimised Solution** (the pattern) → ③ **Space Optimization** (or "already optimal — here's why") → Java → complexity table → interview narration → related problems.

Use the [`_TEMPLATE.md`](./_TEMPLATE.md) to add more. The gold-standard example is [`01-strings-parsing/text-justification.md`](./01-strings-parsing/text-justification.md).

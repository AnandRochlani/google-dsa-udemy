## How to use this list

- **Week 1–2:** Hash Map → Two Pointers → Sliding Window → Strings/Parsing → Linked List → Stacks (the ⭐ ones first).
- **Week 3:** Binary Search → Trees → Graphs → Topological Sort.
- **Week 4:** Heaps → Backtracking → DP → Intervals → Design.
- **Every problem:** brute force out loud → optimise → check space. **Narrate the approach** — that's your GCA score. If you can't recall the pattern in 60 seconds, re-watch that lesson.
- **The ⭐ problems** are the ones most likely to show up at Google. If you're short on time, do all the ⭐ first.

> ~50 problems, 4 weeks, one pattern at a time. That beats 300 problems in random order — every time.
